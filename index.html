Zimbabwe Grocery Market MCP Server

A production-ready Model Context Protocol (MCP) server that enables LLMs to search and compare grocery prices across Zimbabwe's major supermarket chains in real-time.

Key Features

  • Multi-Retailer Support: Scrapes data from Pick n Pay, OK Zimbabwe, and Food World.
  • Real-time Price Comparison: Aggregates and normalizes pricing data for accurate comparisons.
  • MCP Tools: Exposes tools like search_products and compare_prices to LLMs (Claude, etc.).
  • Robust Architecture: Built with FastMCP, BeautifulSoup4, and Pydantic for type safety.

Technical Stack

Python 3.10+ FastMCP BeautifulSoup4 Asyncio Pydantic

Architecture

The system follows a modular design with separate scrapers for each retailer, a normalization layer for data consistency, and an MCP server layer that handles requests from LLM clients.
